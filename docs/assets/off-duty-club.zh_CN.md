# 什么时候下班呐

应用用独立的 240 × 320 陪伴界面替代硬件测试菜单，包含八种情绪、五种不连续重复的摸鱼动效、今日进度、最后一分钟发射倒计时和下班庆祝页。音效在设备本地合成，遵循音量设置，0 为静音。

首页宠物持续呼吸、眨眼、左右观察，并偶尔挥手；首次引导页也包含同一宠物。

## 首次使用首页

首页引导完成 Wi-Fi 连接与对时、作息设置两步。OK 进入当前待办，上键打开网络设置，下键打开作息设置。保存任一上下班时间即确认当前显示的整组作息，并保存完成标记；仅保存亮度不算完成作息设置。旧设置没有该标记时需确认一次作息。已有有效时间锚点和已确认作息时，断网仍保留正常首页；重启后尚未校准则重新显示连接或对时引导。

## 操作和设置

工作主屏：上键切换情绪，短按下键在松手后显示一次三秒摸鱼动效，OK 进入设置。按住超过 0.5 秒进入长按流程，松手只取消、不触发摸鱼。持续按住下键五秒会出现全屏 5→4→3→2→1 倒计时，结束后直接提前下班；提前松手取消。提前下班页上下键放彩带，短按 OK 进入下班首页，长按 OK 进入设置。下班首页展示已开启的自由时间与放松角色，下键触发放松动效，OK 进入设置。恢复按当前校准时间继续计时，不回到开始摸鱼的时刻。提前下班只是内存中的临时状态，不修改或保存计划下班时间。已提前下班时不再自动进入正常的最后一分钟发射页。

设置包含上下班时间、亮度、音量、六档熄屏方式、自动彩蛋、Wi-Fi 配网、立即对时、对时状态、忘记网络和返回。上下键选中，OK 进入编辑，上下键调整，OK 保存。上下班及等待开工时间每次调整 1 分钟，亮度和音量每次调整 5%。长按 OK 取消未完成的编辑并返回。忘记网络需要再次按 OK，上下键取消确认。不会清除其他应用的 NVS 数据。上下班时间不能相同，支持跨午夜作息。

默认北京时间 09:00–18:00，亮度 75%、音量 50%、永不熄屏，自动彩蛋开启且冷却十五分钟。熄屏只关闭背光，第一次按键仅唤醒，不执行原动作。正常下班最后一分钟强制亮屏，并让庆祝页保持可见。保持 Wi-Fi 与计时运行比深睡耗电更多，实际续航尚未测量。

## 连接和对时

选择“连接 Wi-Fi”，设备显示连接临时 WPA2 热点 `OFFDUTY-XXXX` 的二维码，随机密码已包含在码中。使用兼容的手机相机扫码加入热点，即使提示无互联网也保持连接；热点二维码、网络名称、`http://192.168.4.1` 地址与连接状态在同一页展示，手机加入后只更新状态文字；在手机浏览器打开该地址，选择扫描到的 2.4 GHz 网络并输入密码。只有热点接口接受配网，表单使用随机令牌，凭证不回显、不打印日志。热点五分钟后关闭，也可按 OK 或长按 OK 返回关闭。新网络取得 IP 后才替换保存的凭证，连接失败会保留旧凭证供下次启动使用。“忘记网络”只删除本应用的网络键。支持开放和 WPA/WPA2 个人网络，不支持 5 GHz、企业认证和需网页登录的网络。

凭证和偏好保存在设备默认 NVS，不宣称加密存储，不上传云服务。取得 IP 后，SNTP 向 `ntp.aliyun.com` 和 `time.cloudflare.com` 请求时间，使用 ESP-IDF 默认的一小时同步周期。每次成功对时后以 `esp_timer_get_time()` 锚定 UTC，因此刷新延迟不会累计成倒计时误差。断网后保留时间锚点直至重启，未同步的启动显示等待校时，不伪造倒计时。离线漂移和网络对时精度需要实测，不承诺亚毫秒精度。

## 继续上班与加班

下班首页按上键进入两项选择。继续上班按 1 分钟调整日常下班时间，并同步保存到设备设置。加班按半小时选择独立时长，范围 30 分钟至 8 小时，不修改日常上下班时间。选择页显示时长与预计结束时间，跨午夜标注次日。

加班首页显示本次剩余时间与进度，结束前不会显示 100%。沿用最后一分钟动画与心情主题盖章页。短按下键仍是三秒摸鱼；长按下键五秒提前结束本次加班。结束页短按 OK 进入下班首页，长按 OK 仍进入设置。

独立的 `overtime` NVS 记录保存本次起止时间。运行时断网继续计时；重启后通过网络或手机校时恢复本次加班。已结束的加班保留盖章页，直到下一次日常班次开始。选择继续上班时，加班记录与日常设置在同一次保存中清除。原有日常作息数值与分区保留。重启恢复、实体按键、音效和显示仍待真机验收。

## 等待开工与下班页保持

等待开工按班次顺序联动：本次上班、本次下班、等待、下一次上班。默认下一次上班前一小时，09:00–18:00 对应次日 08:00，22:00–06:00 对应 21:00。修改日常上班或下班时刻，会重新计算等待时刻。休息间隔不足一小时，则取本班下班时刻，先观察下班完成状态再开始等待。手动逐分钟调整只提供本班下班起、下一班上班前的合法时刻。设备设置前三项集中展示这三个时间；手机表单同样集中在屏幕和声音偏好之前，并在上下班时间变更时立即更新等待字段。服务端也会拒绝越界的手机提交。

正在进行的跨午夜班次或加班不会被打断。继续上班修改日常作息时同步等待；独立加班不改变日常计划。旧 12/14 字节设置保留其他偏好，缺少 `waitv` 标记时在加载阶段重算新默认，后续保存标记迁移完成。设置结构仍是 14 字节，分区不变。缓存的手机页面需刷新以加载新的联动脚本。

## 三秒开机页

开机只展示已确认的开机设计三秒：奶油色背景、OFF DUTY CLUB / 准点快乐事务所、应用标题、弹动的珊瑚橙问号，以及现有宠物滑入、挥手、轻跳。布局与关键帧时刻对应交互预览；问号和底部小字使用小型字体子集，宠物复用 Flash 图像，限制 RAM 开销。应用以短调度延时等待，LVGL 任务持续渲染。

展示结束后初始化业务服务，进入对应的设置引导、等待开工、上班或下班页面。按键在开机页结束后注册，初始化时仍按住的键会被隔离到松手，避免排队动作误触。单纯熄屏唤醒不重播，冷启动或重启会展示。

## 离线时间恢复

已校准的设备断开 Wi-Fi 后继续倒计时，后台重连不会清除单调时钟基准。真正关机或重启后，基准保持无效，直到取得新的时间；仅有已保存的作息无法确定当前时间。

时间引导页打开现有私有热点，既能配置 Wi-Fi，也能手机校时。手机页新增“使用手机当前时间”表单：通过 CSP 哈希授权的小段本地脚本在提交时读取 `Date.now()`，无需互联网请求。`/time` 仅接受私有热点接口和当前会话令牌，严格校验 2025–2099 年范围内的毫秒时间戳，交由网络任务校准；队列等待时长计入续时，手机时钟误差和传输延迟仍需测量。设置和手机状态显示时间来源，上班首页显示离线续时。

网络可用时 SNTP 校准会替换手机时间。下班仪式按已庆祝的最大截止时间防重复，最后几秒音效只向前推进，时间回调不会重放已完成的截止点。不加入蓝牙、新 NVS 字段或分区，也不将已保存的旧时间伪装成当前时间。熄屏仅关闭背光，不清除时钟基准。

## 资产和验证

`main/offduty_ui.c` 定义界面坐标和绘制，`main/offduty_model.c` 定义可独立测试的时间、设置验证、表单解码和长按计时。复用 BSP，不修改引脚或驱动。网络和音频在工作任务运行，按键回调只把带时间戳的事件入队。禁用蓝牙，LVGL 使用 48 KB 分配池，不创建全屏画布。渲染测试同样使用 48 KB 内存池和 RGB565 输出。

字体许可和生成见[字体资源](../../assets/README.zh_CN.md#下班应用字体)。字库仅覆盖应用界面，不覆盖任意用户文字：设备不显示用户输入的 SSID，网络名称在手机上输入。

激活 ESP-IDF 5.5.3 后运行 `./tools/validate.sh`。实际 LVGL 软件渲染及字形覆盖检查：

```sh
cmake -S tests/offduty_render -B build/offduty-render -DCMAKE_BUILD_TYPE=Debug
cmake --build build/offduty-render -j 8
mkdir -p build/offduty-render/images
cd build/offduty-render/images
../offduty_render ../../../assets/fonts/offduty/characters.txt
```

渲染器导出所有情绪、摸鱼场景、设置选中项、提前下班、下班首页、宠物动作、倒计时边界和庆祝页的 PPM 图像，并用实际 LVGL 字体检查字表和所有可打印 ASCII。它不能证明 LCD 外观、帧率、按键时长、声音、无线连接、NVS 恢复或续航。真机须检查所有页面、五秒长按及取消、恢复、跨午夜下班、错误密码、重连、未校时重启、熄屏唤醒、静音、最后一分钟覆盖，以及显示、联网和音效持续并行运行。

只有当前完整验证通过后才算实现和主机检查完成。设备验收状态见下方；刷写成功不代表实际界面已验收。不要把仅应用镜像刷在零地址，使用当前精确验证的固件包并遵循[数据策略](../development/engineering/firmware-layout.zh_CN.md#烧录与已存数据)。

手机页面也可设置上下班时间、亮度、音量、六档熄屏方式和彩蛋，并显示连接与对时状态，提供立即对时和明确的忘记网络操作。设置经校验后交给应用主任务保存至 NVS；独立状态区域每三秒显示保存结果，不重置编辑内容。页面仍仅允许临时热点访问，五分钟后关闭。设备设置标签和值使用同一字体，按可见字形在行内居中。配网页不显示等待倒计时，仍保留五分钟的热点有效期。

## 主题、恢复上班与手机配网

下班票据和首页心情标签共用八套强调色/文字色。纸张、票据、印章及宠物表情随心情变化，宠物与底部锯齿保持间距。庆祝页上/下键释放十个随机分布的彩带碎片，在所有文字前方从上向下落出屏幕，总时长约两秒。短按 OK 进入下班首页，长按 OK 进入设置但不显示长按提示。

恢复上班页每次调整 1 分钟下班时间。OK 先将新时间保存到设备/手机设置，再从校准后的当前时间开始新班次；保存失败停留选择页，长按 OK 取消。熄屏只有常亮、闲置 1、2、5、10 或 30 分钟六档。保存设置沿用旧二进制布局，旧闲置时间向上取档且最高 30 分钟，旧定时熄屏迁移为常亮。

手机配网页显示最多 16 个支持的附近网络，按信号强度排序，支持重新扫描并保留隐藏网络手动填写入口。网络工作任务负责扫描和连接；扫描失败保留旧列表，不打断凭证连接尝试。SSID 经过转义，请求要求私有热点接口与会话令牌，不记录网络名或密码。独立状态区域每三秒刷新连接、对时和保存结果，不重置编辑内容。

## 全屏摸鱼与宠物放松

下班首页短按下键会启动六种全屏宠物动作之一：伸懒腰、沙发瘫、跳舞、开饭、吐泡泡及小睡。标题、文案、布局和三秒返回进度条跟随已确认的交互。宠物颜色/表情随心情切换，连续选择不重复。上键打断并进入继续上班/加班选择；短按或长按 OK 打开设置。上班摸鱼保留原五种内容和文案，改用相同全屏结构及三秒返回，五秒下键提前下班逻辑保持独立。

宠物图片缓存在 Flash，避免在 48 KB LVGL 内存中逐帧分配透明图层。主机渲染覆盖 48 种心情/动作组合、中文字形、局部/完整帧一致性和动画清理；按键时长与六种无重复选择有纯逻辑测试。每次彩带使用新的硬件随机种子调整位置、入场延迟、形状及颜色，碎片约缩小 15%。保存设置及分区保持不变。新版本的实际动画、字形对齐、声音和按键行为仍需真机验收。

## 手机设置布局与原位反馈

手机配网页将离线手机校时和 Wi-Fi 联网分成互斥视图，移除步骤编号，作息与偏好共用。紧凑状态内容替换占满高度的状态 iframe，原生时间输入框限制宽度，适配窄屏。表单提交留在当前页，显示 loading 后轮询设备，确认保存成功、失败、联网或本次校时完成；HTTP 接收成功不等于保存或校时完成。扫描只更新 Wi-Fi 区域，保留作息编辑内容。连接中断超时后明确提示结果未确认。CSP 仅允许同源请求与精确脚本哈希，保留热点接口和会话令牌校验。

重新上班或加班会清空当前彩蛋动画，并重新计算自动彩蛋冷却；短按 OK 在进入设置前清空动画状态。浏览器验证两条恢复路径正常进入设置，未复现用户描述的异常跳转。iPhone Safari 布局与实体按键表现需真机验收。

## 手机操作的设备确认

手机保存偏好后，设备根据实际存储结果在底部提示成功或失败，持续三秒。每次手机校时完成都会推进修订号，因此重复校时也会出现新的三秒提示。这些操作会唤醒熄屏，保留当前页面并继续倒计时。提示临时替换底部操作说明，二维码与设置地址不受影响；渲染测试验证二维码/地址区域保持一致，提示消失后整帧恢复。Wi-Fi 选项仅显示转义后的网络名称，保持信号排序与连接校验。

## 手机密码显示与隐藏

扫描和手动添加 Wi-Fi 的密码默认隐藏，各自提供独立的显示/隐藏按钮，只切换输入类型，不提交表单。委托事件处理保证扫描替换网络区域后仍可使用。

## 设置与刷新优化

设备和手机标签统一为准备时间、上班时间、下班时间，均支持逐分钟调整；加班时长仍按半小时调整。准备时间默认下一次上班前一小时，随作息修改联动。首次使用默认 09:00–18:00、亮度 75%、音量 50%、常亮，已保存偏好保持不变。

重新上班结束后，到下一次有效准备时刻清除恢复班次，避免等待页被覆盖至上班时刻。Wi-Fi 连接成功需等待网络配置的存储结果，存储失败与连接状态分别显示。等待页跳过无变化帧，宠物或倒计时变化时刷新中部 120 行，仅在百分比变化时刷新小块充能区域；主机帧与完整重绘逐帧对比。删除未使用的 47 px 时钟字体，8 px 子集只保留等待页页眉和心情名称；节省的是 Flash，而不是运行时 RAM。

本轮优化验证：Build PASS；Host tests PASS，覆盖逐分钟表单、旧偏好保留、恢复班次的准备边界、存储失败状态和 LVGL 局部/完整帧一致性。归档 `build/firmware/3daee2b5683a884377e106aeadf36bc2aba47c4561daa6a0ef62e72164386fe8/`，ELF SHA-256 `00ea0f17ec1a3783bd664b14decfcf03795f1d66ea3a07df3e2084f65d7d31a8`。应用大小 2,781,168 字节，比上次烧录减少 18,864 字节。本轮 Device tests：分段写入及哈希校验、原分区表一致性、35 秒启动观察 PASS。运行 ELF 前缀为 `00ea0f17e`，版本 `1.0.0`，开机页 3,003 毫秒，无错误或崩溃标记，监视已关闭。实际 UI、流畅度、实体按键逐分钟编辑、手机保存和 Wi-Fi 配置存储仍待真机验收。
