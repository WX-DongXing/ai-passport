# Sound Wave 声波应用

Sound Wave 1.0.0 是面向 AI Passport 240 × 320 屏幕的离线麦克风可视化应用。
根目录 CMake 配置中的 `PROJECT_VER` 设置固件内嵌版本。启动显示独立的
中文标题和动态曲线，至少 1.4 秒后自动进入 SINE 实时视图。
启动和导航不使用基线测试菜单。

## 按键

| 按键 | 行为 |
| --- | --- |
| UP 短按 | 循环切换正弦波、镜像声波、原始 PCM 波形 |
| DOWN 短按 | 切换横屏／竖屏方向 |
| OK 短按 | 暂停／继续曲线和读数 |
| OK 长按 | 进入横屏全屏／返回普通竖屏 |

全屏只显示声波和简洁的 Hz／dBFS 读数，隐藏电量、标题、状态和提示。
仍支持切换形态、方向和暂停。
暂停时继续读取麦克风，恢复时展示当前声音，不回放积压的旧采样。
没有确认弹窗和校准页面，设备使用验证过的 14／22 px 中文字体子集。

## 读数与视觉映射

采集采用 BSP 固定输入增益、16 kHz 单声道 16 位 PCM，每块分析 512 个采样
（32 ms）。加 Hann 窗的 FFT 估算最强频谱峰值，频率间隔为 31.25 Hz，并作
频点间插值。它不是基频检测器，混合声音可能产生不同峰值。安静或没有突出
频谱峰值时显示 `-- Hz`。插值后最低报告峰值约 47 Hz，上限低于 8 kHz。

dBFS 按去除直流后的 `20 log10(RMS / 32768)` 计算，最低显示 -96 dBFS。
满幅正弦波约为 -3.01 dBFS。这是数字输入电平，不是经过声学校准的 SPL 或
dB(A)，不承诺环境声级测量精度。接近满幅时普通模式显示 CLIP；输入失败时
显示 MIC ERR 和不可用读数，并每秒重试一次采集。

正弦波是主频控制可见周期数的单条视觉曲线，不是原始示波器轨迹。
镜像声波对称展示绝对局部 RMS，原始波形保留每个显示桶中带符号的 PCM 峰值。
两者都不进行每帧归一化。使用固定 16 倍视觉增益，屏幕裁切前高度与输入幅度
成比例，输入增加 6.02 dB 时高度翻倍。普通模式的读数与曲线使用同一帧，
没有自动视觉增益或校准弹窗。

三种风格分别使用纯色背景：紫色斜向轨道与淡紫正弦、灰紫对称沙漏曲线与淡粉镜像、
墨紫透视线网与珊瑚色原始波形。不使用渐变、叠层声波或模糊效果。
方向／风格切换不改变 Hz／dBFS。每次绘图后等待 33 ms，实际帧率、延迟、
麦克风底噪、耗电和频率准确性仍需设备验收。

应用使用一个永久 LVGL 页面、只保留最新帧的队列、有界按键队列和一个音频
工作任务。不保存录音、不播放音频、不启动联网、不分配整屏位图。
只有 UI 所有者持 BSP 锁访问 LVGL。固件保持仓库默认分区。

绘图通过 LVGL 9.5 自定义图像解码回调分块生成 RGB565，使用单个对齐的
5120 字节缓冲和单个软件绘制单元，不分配完整位图或屏外 ARGB 图层。
主机测试对比分块／整图结果，检查像素高度比例和局部裁切写入边界。

## 验证与设备验收

激活 ESP-IDF 5.5.3 后运行完整验证：

```bash
./tools/validate.sh
```

主机测试覆盖 FFT 测试音、幅度比例、直流去除、削波、弱输入、控制状态、
镜像对称性和曲线边界。设备上检查开机、三种形态、OK 短按／长按分离、
暂停／继续、全屏简洁读数、横竖方向、中文字符、安静环境、参考纯音响应、
削波和持续采集／显示稳定性。
使用匹配的归档固件和 ELF，并遵循
[烧录与数据策略](../development/engineering/firmware-layout.zh_CN.md#烧录与存储数据)。

采集任务每次分析后显式让出 CPU，显示更新不追赶错过的时限。曲线使用三角
函数递推，避免逐点调用三角函数。采集和显示日志报告耗时与剩余堆，便于有界
设备验收。

本版直接展示最新采样帧，使用固定相位动画速度；没有平滑滤波、速度调节、
设置面板或长按上键操作，保留轨道正弦和沙漏镜像背景。

恢复后的应用此前通过完整主机／构建／归档验证及 60 秒设备运行观察，未发现
看门狗、panic、缺字或麦克风不可用错误，报告的剩余堆保持 212000 字节，
普通竖屏正弦约 13.1–13.2 帧／秒，日志记录全屏和风格切换。这是更新版本元数据
之前对恢复行为的验证，1.0.0 精确构建产物仍需实机验收。实际显示、声学准确性、
所有按键及更长时间稳定性仍需设备／仪器检查。固件二进制和本地串口日志不纳入提交。
